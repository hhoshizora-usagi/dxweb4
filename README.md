# dxweb4
DX Web の基本形（dxweb2 の `04-light-line`）に、ヘッダー・フッターのホバー演出 6 種を組み込んだアレンジ集です。
ページ構成・文章・写真・レイアウトは dxweb2 の基本形をそのまま使い、ヘッダーのメニューとフッターのリンクにマウスを乗せたときの演出だけを種類ごとに変えています。

| No. | ディレクトリ | アニメーション | 担当 |
|--|--|--|--|
| 01 | 01-underline | 下線がスゥッとスライド | Underline |
| 02 | 02-fill | 背景がふわっと塗られる | Fill |
| 03 | 03-glow | 文字がほんのり光る | Glow |
| 04 | 04-expand | 文字間隔が広がる | Expand |
| 05 | 05-lift | 要素が浮き上がる | Lift |
| 06 | 06-reveal | 下線がスライドして現れる | Reveal |

## 使い方
- `index.html`（ルート）は一覧ページです。
- 各ディレクトリの `index.html` をブラウザで開くと、ヘッダー・フッターにマウスを乗せて確認できます。
- 基本形は dxweb2（`04-light-line`）から借りています。

## ファイル構成
- `assets/style.css` … dxweb2 共通スタイル
- `assets/v04.css` … ライト＆ライン（基本形）の上書きスタイル
- `assets/main.js` … スライダーやスクロール演出
